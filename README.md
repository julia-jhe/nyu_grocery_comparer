# NYU Grocery Price Comparer


## Problem

Grocery prices vary across stores around NYU. Collecting price information and forming comparisons manually can be a tedious and inefficient process, especailly for new students. Without this information, however, students risk spending more money than necessary. 


## Objective

Develop a Python tool that helps compare the prices of individual grocery items and basket totals across stores near NYU. 


## Intended users

NYU students who purchase groceries around the Washington Square campus.


## First version plan

    - Include three grocery stores near campus
    - Include three common products from each store
    - Use manually collected price data
    - Compare individual and basket total prices
    - Run as a console-based Python program using CSV


## Data

Prices for the first version will be collected manually. Each product will be recorded by product type, store name, product details, package size, unit, regular price, collection date, brand, store locaiton,source, and notes, if any.


## Status

Initial planning and data collection. No functioning code has been written yet.
