# Data Collection Method


## Region

Grocery stores within walking distance of NYU's Washington Square Campus.


## Stores (3)

Morton Williams, Trader Joe's, Whole Foods Market


## Products (3)

- pasta
- pasta sauce
- black beans


## Information Collected

    - Store name
    - Product type
    - Product details
    - Package size
    - Unit
    - Regular price
    - Collection date
    - Brand
    - Store location
    - Source (URL) 
    - Notes (if any)


## Collection Rules

Product details, brand, and store address are recorded but does not affect ranking; they can be shown if the user wishes to. Products from different stores are only compared when they have the same basic criterias, which includes product type, size, and unit. Only regular prices are collected in the first version. Prices will be collected within the same general time period.

For each product at each store, the item with the lowest regular price that meets the required comparison criteria is selected (product details will also be matched as closely as possible). Brand and bestseller status do not determine which item is selected. The selected item's brand and other details are recorded for transparency. If no item meets all required criteria, the closest match is selected and its differences are explained in the 'notes' column; if no reasonably comparable item is available, the product is recorded as unavailable.
